## 👨‍💻 About Me

- 🧠 **Full Stack Developer Jr** con formación en **Backend** y **Frontend**.
- ⚛️ Desarrollo interfaces modernas y responsivas con **React.js**, componentes reutilizables, manejo de estado y consumo de APIs.
- 🔥 Experiencia trabajando con **Firebase**, especialmente en integración de datos y funcionalidades para aplicaciones web.
- 🖥️ Desarrollo y mantenimiento de **APIs RESTful** con **Node.js + Express**.
- 🗄️ Trabajo con bases de datos **SQL y NoSQL**, incluyendo **MySQL** y **MongoDB**.
- ⚡ Implemento funcionalidades **real-time** usando **Socket.IO** para chats, eventos y notificaciones.
- 🔐 Manejo autenticación con **JWT**, middlewares, validaciones, sanitización de datos y buenas prácticas de seguridad.
- ☁️ Experiencia integrando servicios externos como **Cloudinary** para manejo de imágenes y archivos.
- 🧪 Uso herramientas como **Postman**, **VS Code**, **Git**, **GitHub** y **MySQL Workbench** en mi flujo de trabajo.
- 📈 También cuento con experiencia administrativa, gestión de datos, facturación, cotizaciones y optimización de procesos internos.
- 🌱 Actualmente sigo fortaleciendo mis conocimientos en **TypeScript**, testing, arquitectura escalable y buenas prácticas Full Stack.
